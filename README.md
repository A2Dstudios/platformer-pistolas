- [x] Observers

- [x] UI amb puntuació (bug, només l'ultim enemic da punts)
- [x] Layers, triggers, colliders...
- [x] Logica i estructura

- [x] Tilemaps amb colisions i de decoració
- [x] Partícules amb particle system
